# -
ПрофиТрек — современный веб-сервис для профориентации школьников. Пользователь проходит интерактивный тест из 20 вопросов, после чего система анализирует ответы и определяет подходящие профессиональные направления, профиль пользователя и наиболее подходящие профессии. Проект создан на HTML, CSS и JavaScript и не требует сервера или базы данных.
